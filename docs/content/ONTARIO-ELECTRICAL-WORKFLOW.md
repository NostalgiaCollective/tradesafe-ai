* Remaining bonding, panel, wiring and testing prompts need licensed clause/version mapping and qualified applicability review; generic wording and photos do not establish technical compliance or absence of voltage.

Requested decisions: confirm scope exclusions, legal-role boundaries, credential categories/exemptions, exact Code references and transition rules, prompt omissions, record attribution and the intended qualification scope of each reviewer. ## Implementation boundaries

One electrical-job context per company site; use a separate site for separately scoped jobs. Supervisor/owner saves create immutable revisions; workers read under the existing company-site/report access model and use existing concern/action mutations. Internal review is tied to its saved baseline and cleared on subsequent edits. Credential check records are user attestations, not TradeSafe registry validation; editing credential fields clears the current check while retaining historical revisions.

Inspection/certificate attachments reference ready, immutable photos on finalized electrical reports explicitly linked to the same site/company. Existing JPEG/PNG/WebP and resource limits remain. No arbitrary document/PDF upload, authenticity validation or alteration of retained PDFs. The electrical HTML export is an exact saved revision including site/content snapshots and hashes; the existing site package remains a separately scoped export of reports, briefs and actions. No silent claim that the site ZIP contains electrical context revisions.

Unknowns and incomplete documentation can be saved; there is no compliance score or permission-to-work state. New content review decisions do not rewrite saved electrical revisions, briefs, acknowledgements or reports. Credentials and review statuses are independent of application role permissions.
